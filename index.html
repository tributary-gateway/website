Tributary

High-throughput, low-latency AI gateway. Route requests across OpenAI, Anthropic, and other providers with one API.

GitHub Read the Docs

Why Tributary?

Fast

Built on Rust + Tokio. Sub-millisecond proxy overhead. No Python runtime.

Multi-provider

OpenAI, Anthropic, and more through a single OpenAI-compatible API.

Observable

Built-in metrics, logging, and cost tracking per request and per key.

Production-ready

Rate limiting, auth, hot-reload config. Docker, binary, Kubernetes.

Get started in 30 seconds

docker run -p 8080:8080 \
  -e OPENAI_API_KEY=sk-your-key \
  tributary-gateway/tributary:latest
